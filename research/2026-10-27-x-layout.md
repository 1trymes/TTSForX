# X layout change and missing speaker controls

On 2026-10-27 the signed-in X home feed and a post detail page used plain
`article` elements without the old `data-testid="tweet"` or `tweetText`
attributes. Posts exposed `data-engagement-action="reply"` and a text `div`
with `dir="auto"`, `whitespace-pre-wrap`, and `wrap-break-word`. The More
button used the `#icon-more-dots-hor` SVG symbol. Both inspected surfaces
matched these selectors; the old selectors could not find their posts.

The extension now supports this layout alongside the existing test-id layout.
The DOM regression tests cover mounting and initiating playback, the action
row fallback, quoted text exclusion, and the old layout. The live selectors
were checked read-only on the open X post and home feed; audio playback was
not tested against the installed browser extension.
